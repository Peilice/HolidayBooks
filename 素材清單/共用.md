# 共用素材清單

合計 **12 張**，放 `共用/圖/`。先做這批，各本再引用。規格與作法見 [總則](總則.md)。

## 前綴

```text
兒童精裝繪本插畫，不透明水彩（gouache）質感，輕微紙紋。
暖色、低彩度，不用螢光色和彩虹配色，不用純黑和純白。
造形圓潤簡單，以色塊分形狀，墨藍色（#263042）柔和細輪廓線。
人物頭身比約 1:3，臉部簡單：點點眼、小腮紅、小嘴巴，不要大眼萌系。
構圖乾淨、留白多，遠看也能認出主角。
不要任何文字、數字、印章、簽名、浮水印、邊框、3D、照片質感。
```
