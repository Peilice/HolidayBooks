# 聖誕節〈聖誕老公公的秘密〉素材清單

底圖 7 張、去背圖 27 張、書櫃封面圖 1 張，合計 **35 張**（不含共用素材）。規格與作法見 [總則](總則.md)。

## 本書前綴（開新對話時貼一次，之後逐張貼）

```text
兒童精裝繪本插畫，不透明水彩（gouache）質感，輕微紙紋。
暖色、低彩度，不用螢光色和彩虹配色，不用純黑和純白。
造形圓潤簡單，以色塊分形狀，墨藍色（#263042）柔和細輪廓線。
人物頭身比約 1:3，臉部簡單：點點眼、小腮紅、小嘴巴，不要大眼萌系。
構圖乾淨、留白多，遠看也能認出主角。
不要任何文字、數字、印章、簽名、浮水印、邊框、3D、照片質感。
本書配色：雪夜藍（#22365c）、杉樹綠（#2f6b4f）、朱紅、燭光黃、雪白。
本書角色，每張圖都要一致：
- 尼古拉：聖尼古拉，白鬍子的慈祥老人，朱紅長袍白滾邊、朱紅尖帽白毛邊、棕色靴子
- 爸爸：棕色舊外套、棕色短鬍
- 三姊妹：大姊棕髮雙辮、磚紅洋裝；二姊黑色短髮、灰綠洋裝；小妹棕髮雙辮、芥黃洋裝，身高由高到低
- 小朋友：約六歲，灰藍舊外套、深棕髮
```

## 注意

- 襪子三隻是紅、綠、紅，用兩款圖重複使用。
- 禮物盒需要三種顏色時，用網頁 filter 調色或另存三色。
- 右手「噓」已畫進姿勢，不再需要現有程式的 hush-arm。
